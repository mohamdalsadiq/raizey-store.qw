# المطلوب من المالك وخيارات معالجة الإيصالات وتكلفتها

تاريخ المراجعة: 6 نوفمبر2026. إفادة المالك: لا يوجد توثيق حالي، وآخر لوحة أظهرت المستوى المجاني. لا تُعتبر هذه الإفادة موافقة على تشغيل المعالجة، ولا موافقة العميل بديلاً عن شروط المزود. لم تُفعّل فوترة أو خدمة مدفوعة ولم تُرسل صور إيصالات حقيقية للاختبار.

## المطلوب منك بالضبط — قراءة فقط، دون تفعيل شيء

1. افتح [Google AI Studio: المشاريع والمفاتيح](https://aistudio.google.com/api-keys)، وحدد **المشروع المرتبط بالمفتاح الذي سبق إعداده لفحص المتجر** من سجل إعدادك. المطلوب اسم/معرّف المشروع واسم الخدمة Developer API أو Vertex، لا قيمة المفتاح ولا صورة له. إن لم تستطع ربط المفتاح بالمشروع، اكتب «الربط غير معروف»؛ لا نستنتجه من اسم السر أو اشتراك تطبيق Gemini.
2. من المشروع نفسه، سجّل **اسم الخطة الظاهر الآن وتاريخ الاطلاع** وكون Cloud Billing مرتبطاً/مفعّلاً مسبقاً أو غير مفعّل. اترك أزرار التفعيل والترقية كما هي. اسم المشروع والخطة وحالة الفوترة يكفون؛ لا نحتاج رقم بطاقة أو عنوان فوترة أو OTP أو حساب فوترة كامل.
3. حدّد بلد النشاط/صاحب الحساب والبلدان المستهدفة للعملاء، ثم راجع [المناطق المتاحة](https://ai.google.dev/gemini-api/docs/available-regions). لا تفترض أن وجود South Sudan يعني Sudan، ولا تغيّر البلد أو تستخدم VPN لتجاوز الشروط. الفوترة لا تلغي قيد المنطقة.
4. للمشروع والخدمة المحددين، وثّق رابط وتاريخ/نسخة [شروط Gemini API](https://ai.google.dev/gemini-api/terms) أو شروط Cloud المطابقة، وما ينطبق على استخدام المدخلات للتدريب/تحسين المنتجات، والمراجعة البشرية، والاحتفاظ وسجلات إساءة الاستخدام، وحذف البيانات وأي استثناء إقليمي أو إعداد logging/sharing. «لا أعرف» يبقي التفعيل معلّقاً؛ لا نضع وعداً بعدم التدريب أو الاحتفاظ.
5. إن كان النموذج مثبتاً في إعداد المتجر، اذكر اسمه فقط. وإن كان الاكتشاف/التبديل تلقائياً فاذكر ذلك؛ أسعار النموذج البديل قد تختلف. لا نحتاج GEMINI_API_KEY أو SUPABASE_SERVICE_ROLE_KEY أو ملفات env.

يمكنك إعادة المعلومات كنص مختصر: `المشروع / الخدمة / الخطة وتاريخها / حالة الفوترة الحالية / بلد النشاط وبلدان العملاء / رابط الشروط وملخص logging والاحتفاظ / اسم النموذج أو اكتشاف تلقائي`. لا ترسل بيانات عميل أو صورة إيصال للتحقق من الخطة.

## الخيارات المتاحة الآن

|الخيار|التكلفة|ما يعنيه|
|---|---|---|
|بقاء مسار الموافقة الجديد غير مفعّل حتى اكتمال الإثبات|0 دولار رسوم مزود لهذا العمل|التصميم والخطوط والأيقونات والأصول وSEO تستمر مستقلة. لا يُقدَّم هذا كتشغيل فحص مجاني متوافق.|
|Gemini Developer API بخطة وشروط ومنطقة مناسبة، إذا قررت لاحقاً استخدام المدفوع|مثال Gemini3.1Flash-Lite:0.25دولار لكل مليون توكن إدخال نص/صورة/فيديو، و1.50دولار لكل مليون توكن إخراج، وفق السعر الرسمي المرجعي|عرض تكلفة مشروط، وليس تفويضاً بتفعيل billing أو دليلاً أن كل بيانات مالية مسموحة. يلزم فحص الشروط والتوفر والإعدادات أولاً.|
|OCR وتصنيف بصري مستضافان ذاتياً على جهاز تملكه بالفعل|قد تكون رسوم الترخيص0 بأدوات وتراخيص مناسبة؛ الكهرباء والتجهيز والصيانة غير مقدرة دون مواصفات الجهاز|Tesseract يوفر OCR بترخيصApache2، لكنه وحده لا يستبدل شرط التصنيف البصري. يلزم نموذج بصري مرخص وتقييم دقة وأمان وأداء وحماية تخزين. لا إرسال الصور لمزود خارجي لهذا المسار.|
|استضافة ذاتية على GPU مستأجر|مثال سعرGPU T4:0.35دولار/ساعة، أي255.50دولار عند730ساعة، **للـGPU وحده**؛ تضافVM وRAM والتخزين والشبكة والضرائب بحسب المنطقة|مثال يوضح أن الاستضافة الذاتية السحابية ليست مجانية؛ ليس عرضاً نهائياً ولا اختياراً أو حجزاً لخادم. يلزم تسعير كامل قبل القرار.|

مصدر أسعار التوكنات: [تسعير Gemini](https://ai.google.dev/gemini-api/docs/pricing) و[دليل Gemini3](https://ai.google.dev/gemini-api/docs/gemini-3). مصدر مثالGPU: [Google Cloud GPU pricing](https://cloud.google.com/products/compute/gpus-pricing). ترخيص OCR: [Tesseract الرسمي](https://github.com/tesseract-ocr/tesseract). قرئت نتائج المصادر الرسمية المتاحة؛ بعض صفحات النص الكامل أعادت خطأ content-type/تحويلاً، لذلك يجب إعادة تأكيد السعر والشروط الحالية من المشروع قبل أي التزام.

### مثال حسابي واضح، وليس فاتورة أو قياساً حقيقياً

نفترض **إجمالي المرحلتين معاً لكل صورة**4000توكن إدخال بما فيها الصورة، و1000توكن إخراج، بلا retries أو نموذج أغلى أو أدوات إضافية:

`تكلفة الصورة = (4000×0.25 +1000×1.50) ÷1,000,000 =0.0025 دولار`

- 1000صورة:2.50دولار تقريباً.
- 7500صورة في30يوماً:18.75دولار تقريباً، إذا كانت كل صورة تستدعي مرحلتين فقط. حد500استدعاء/يوم يعني250صورة ذات مرحلتين نظرياً قبل retries وباقي القيود، ولا يضمن تنفيذها أو سرعتها.
- إن تضاعف الإجمالي إلى8000إدخال و2000إخراج، يصبح المثال5دولارات لكل1000صورة و37.50دولار لكل7500صورة.

الأرقام افتراضات حسابية وليست توكنات مقاسة من إيصالات المتجر. إعادة المحاولة والتبديل إلى نموذج أغلى وthinking tokens والضرائب وتحويل العملة قد تغيّر التكلفة. لا يُعتبر budget alert منGoogle سقفاً صلباً يمنع كل الإنفاق. راجع العداد الخادمي والحصص وتثبيت نموذج مقبول وتسعيره قبل الإطلاق؛ لا تصفّر العدادات الحقيقية.

## توصية حالية ضمن طلبك

أبق التفعيل الجديد معلّقاً بتكلفة مزود0 الآن، واجمع البنود الخمسة أعلاه دون تشغيل فوترة. إذا ثبت أنه Unpaid ولا ينطبق استثناء موثق مناسب، فلا تستخدمه لصور الإيصالات الحساسة؛ اختر استضافة ذاتية موثقة أو خدمة ذات شروط ومنطقة مناسبة بعد عرض التكلفة واتخاذ قرار مستقل. الموافقة المسجلة لا تغيّر أي شرط للمزود.

دالة الإنتاج القديمة لم تُنشر مجدداً في هذه الدفعة؛ ذلك لا يثبت ملاءمة مشروعها. لا ترسل لها صوراً حقيقية إضافية للتحقق من الخطة. ما جُهز هنا هو مسار إطلاق جديد محكوم ومغلق على staging إلى أن تكتمل المراجعة.
