# إعادة بناء كتالوج RAIZEY

تم اعتماد نموذج مستقل للكتالوج:

```text
القسم
└── التصنيف
    └── المنتج
        └── الخيارات والأزرار
```

## صفحات الأدمن

توجد الآن ثلاث صفحات مستقلة لإدارة الكتالوج:

| الصفحة | الاستخدام |
|---|---|
| `admin-sections.html` | إنشاء القسم باسمه وترتيب عرضه وحالته. |
| `admin-categories.html` | إنشاء التصنيف باختيار القسم، الاسم، الوصف، الصورة، الترتيب، عمولة الإحالة، والحالة. |
| `admin-products.html` | إنشاء المنتج باختيار التصنيف، الاسم، الوصف، شرح المنتج، الصورة، السعر الأساسي بالدولار، الخيارات، الترتيب، الحالة، والبيانات المطلوبة. |

## طريقة إضافة كتالوج جديد

أولًا افتح صفحة **إدارة الأقسام** وأنشئ قسمًا مثل «الاشتراكات» أو «شحن الألعاب». بعد ذلك افتح **إدارة التصنيفات** واختر القسم الذي ينتمي إليه التصنيف، ثم املأ الصورة والوصف وعمولة الإحالة والحالة. أخيرًا افتح **إدارة المنتجات** واختر التصنيف، ثم أضف المنتج.

عند تفعيل الخيارات داخل المنتج، يمكن إدخال عناصر مثل `60` و`325` و`668` مع سعر كل خيار. ستظهر هذه العناصر في صفحة التصنيف كمعاينة صغيرة، وفي صفحة تفاصيل المنتج كأزرار اختيار فعلية، بدل إنشاء بطاقة كبيرة مستقلة لكل خيار.

## الأرشفة

تمت أرشفة الكتالوج السابق بتغيير `is_active` إلى `false` بدل حذف الصفوف. بقيت الطلبات وعددها 27 محفوظة، ولم يتم تعديل جداول المحفظة أو المدفوعات أو المستخدمين. جدول الأقسام الجديد يبدأ فارغًا حتى يضيف المدير الأقسام المطلوبة يدويًا.

## واجهة المتجر

الصفحة الرئيسية تعرض كل قسم فعّال بعنوان مركزي واضح، وتظهر تحته التصنيفات المرتبطة به كبطاقات. الضغط على التصنيف يفتح صفحة الباقات، والضغط على الباقة يفتح تفاصيل المنتج والخيارات والبيانات المطلوبة ثم مسار السلة والشراء الحالي.
